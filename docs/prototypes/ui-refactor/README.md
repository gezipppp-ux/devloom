## 打开与评审

直接用浏览器打开 `review.html`。它已内联 CSS、设计变量和 JavaScript，可独立运行；其中 PRD 和图册链接仍指向仓库中的文档。`index.html` 是分文件开发入口，需要相邻文件和仓库中的新设计变量保持相对位置。

侧栏「界面目录」可访问 46 个桌面主页面／关键状态；48 张参考图中的 2 张移动布局由同一套响应式页面呈现。移动端先打开左上角菜单，再进入界面目录。目录还提供空内容、加载中、加载失败、权限失效和只读状态演示。

建议评审顺序：

1. 工作台、项目与事项列表的留白和信息密度。
2. 新建事项 → 分派 → 查看开发任务 → 准备环境 → 开始开发 → 批准模拟检查。
3. 会话发送消息 → 查看代码 → 整理交付 → 发布 → 核对三项标准 → 通过验收或填写退回原因。
4. 在 1920×1080、2560×1440 和移动端切换窗口，检查导航、正文宽度、表单底部和弹窗。
5. 从界面目录补看资料、设置、管理、首次使用、冲突和未知执行结果。

所有数据均为虚构。主要流程使用内存状态联动；低频管理表单展示模拟保存反馈，并不复刻完整后台。刷新或「重置演示」恢复初始状态。不要填写真实密码或密钥；原型不进行认证、不调用 Git／Agent／MCP，也不写入业务数据库或浏览器持久化存储。

## 文件职责

| 文件 | 用途 |

## 正式实现范围

- 右上角头像统一打开账号卡片，显示真实显示名称、用户名和角色；个人中心进入现有个人设置页。
- 侧栏低频区仅管理员保留管理中心；移动导航移除重复的个人设置与退出入口。
- 语言和外观复用共享选择组件，切换保留当前页面、表单草稿与账号身份。桌面不再重复显示顶栏偏好入口。
- 手机端头像始终可达，账号卡片重排为底部模态面板，退出位于独立底栏，长内容局部滚动。小屏全局搜索保留在导航内。
- 点击外部或 Escape 关闭账号卡片；选择框展开时，Escape 先关闭选择框。手机端管理焦点、背景滚动和返回触发点。
- 退出调用现有账号退出流程，不增加生产确认步骤；原型的“演示退出”仅用于避免影响真实登录。

## 验证

原型在 Windows / Edge 检查七种 CSS 视口：1920×1080、2560×1440、1440×900、1280×720、768×1024、390×844、320×740。21 张整页视口截图，另检查英文长账号、暗色、入口点击、外部关闭与键盘焦点；脚本错误和外部请求均为 0。

原型截图与验证摘要在忽略目录 `state/browser/account-menu-proposals/`。正式界面的截图由 `test/browser/account-menu.test.cjs` 和主题回归生成到 `state/browser/accounts/`，最终版本专项截图在 `state/browser/account-menu-final/`；完整实施验证记录见 [B 方案验收](../../../reviews/account-menu-b-2026-10-16.md)。

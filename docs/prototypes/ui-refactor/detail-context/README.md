## 正式实施

- 从事项／开发队列进入详情保留来源列表的项目范围、筛选、查询与分页；返回按钮、刷新与浏览器历史均沿用该来源。项目内入口保留原路径，事项详情面包屑不再显示项目概览。
- `IssueAssignment`、`IssueInformation` 为两个详情页共用组件；开发页的 `DevelopmentTaskContext` 读取当前来源事项，切换、刷新、请求失败和撤权互相隔离。
- 分派摘要复用既有历史。只增加事项详情响应的派生属性，不增加数据表、数据库字段或迁移；任务快照、身份、工作树及执行逻辑不变。
- 自己认领与他人指派分别表达。缺失历史时明确显示待确认，释放后显示未分派。分派语义与权限详见[流程契约](../../../engineering/workflow-actions.md)。

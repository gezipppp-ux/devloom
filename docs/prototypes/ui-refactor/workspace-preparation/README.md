## A 实施边界

- 点击创建后立即显示提交状态；受理后在原位显示真实的验证、下载、整理和就绪状态。
- 准备中每两秒查询本人空间；最近进度超过三十秒时解释暂无更新，断网或响应未知时继续确认同一请求。
- 失败保留账号选择；只有明确重试才创建新请求。已受理或结果未知时不能重复点击创建。
- 可以先浏览项目，再从「代码与环境」返回；就绪后明确点击打开工作台，不自动开始开发。
- 展示准备开始及最近进度时间，不展示原始 Git stderr、凭据或服务器目录。
- 原型中的顶栏入口属于方案对照；A 正式入口沿用项目内「代码与环境」，不新增全局克隆队列。

进度在个人开发空间中持久化，详情见[工作空间契约](../../../engineering/workspaces.md)。原型截图：`state/browser/workspace-preparation/`；正式页面截图及专项状态：`state/browser/development-flows/space-preparation/`。

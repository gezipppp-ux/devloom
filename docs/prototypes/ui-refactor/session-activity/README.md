# 会话过程提示 · 三方案评审

日期：2026-10-20。阶段：用户已选择 A，已接入正式 Vue 会话页；本目录保留三方案原型供设计追溯。

[打开原型](index.html)。本地 HTML 可直接打开，顶部切换 A/B/C 和演示状态。所有数据、指令、确认动作只在内存中模拟，无业务 API、Agent 或 Git 调用。

## 页面目标与层级

用户主要阅读回复、补充指令，仅在需要时追查过程。会话标题、正文、代码变更入口和输入区沿用现有页面结构。正常过程不逐条套卡片、不默认展开长命令，不重复展示「已记录」「退出码 0」。错误、待确认请求始终在正文可见，不能随普通过程一起收起。完整命令、输出、思考摘要和文件记录仍可按需查看。

| 方案 | 默认呈现 | 查看详情 | 取舍 |
| --- | --- | --- | --- |
| A · 单行摘要（推荐） | 连续过程压成 32px 的一行，显示当前动作与活动数 | 原位展开时间顺序记录，再展开单条详情 | 兼顾正文空间、上下文位置与可发现性 |
| B · 分类合并 | 思考、命令、文件三个紧凑入口，加一行当前动作 | 每次展开一个类别 | 定位文件或命令较快，占用约两行；分组视图弱化时间顺序 |
| C · 底部状态条 | 正文没有普通过程条目；输入框上方显示约 36px 状态条 | 桌面右侧详情，手机底部面板 | 正文最清爽，查看过程需切换阅读位置 |

以上为桌面原型的内容高度；手机交互目标至少 44px，长内容自然换行。正文限制行宽，桌面独立滚动；手机自然滚动并预留底栏空间。抽屉使用原生 dialog，支持 Escape、焦点限制和关闭后返回触发点。动画尊重减少动态效果偏好。

## 可体验内容

- A 的整段折叠及单条命令展开；B 的类别切换；C 的过程抽屉。
- 执行中、已完成、失败、待确认、空会话、归档只读及停止状态。
- 错误始终可见，点击定位失败详情；确认请求明确允许本次或拒绝，原型只更改模拟状态。
- 输入框可填写并模拟发送；切换方案和语言保留草稿。用户正文和示例输出保持原文，UI 控件支持中英文。
- 代码变更入口显示模拟文件清单。长路径、命令和输出在详情中完整可读。

## 正式实施边界

正式实现位于 `web/src/features/session/SessionTimeline.vue`、`SessionItem.vue` 和 `session-activity.js`。复用现有事件、文件查看、审批、输入、国际化和设计变量；保持 session/turn/item 身份、时间顺序和原始记录，不改变事件存储或执行行为。A 只合并已知同一轮、相邻的普通过程条目，不跨用户消息、助手回复、执行计划或错误聚合；没有 turnId 的记录不相互合并。审批与澄清请求仍由原组件独立展示。正在执行也默认折叠，增量更新、历史分页和失败导致的分组拆分保留用户展开状态；切换会话清空。

摘要显示真实当前活动类型与记录数，不采用原型中示意的语义阶段、耗时或修改文件数。仅展示已有思考摘要，不生成额外推理内容。正在进行的活动已有状态时，省去重复的通用执行提示。非零退出码和错误信息直接可见；完整命令、输出和差异按需展开。窄屏导航可横向滚动，对话区至少保留 240px，空间不足时滚动页面仍可到达输入框。

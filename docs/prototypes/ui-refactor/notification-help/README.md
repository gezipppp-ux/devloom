## 正式实现规则

- 用 `window.isSecureContext` 判断浏览器安全上下文；读取 `location.protocol`、`hostname`、`origin` 解释当前访问方式。不可只用“是否 IP”或“域名 + HTTPS”判断可用性。
- 非安全上下文优先显示连接指导，避免将浏览器报告的 `denied` 误认为用户手动拒绝。当前来源从 `location.origin` 生成；示例 IP 不硬编码进生产。
- HTTPS 域名和有受信任证书的 HTTPS IP、可信本机 HTTP、已设置浏览器安全例外的来源不显示连接警告。
- 安全上下文下区分 API 不支持、未授权、已拒绝、已授权。只有明确用户点击时才申请通知权限；拒绝时指导恢复网站权限。
- 权限和安全上下文重新检测使用真实浏览器状态；不得把点击“重新检测”当作成功。浏览器 flags 只作为可信内网临时选项，不推荐禁用全局安全校验。
- 不影响账号通知偏好、待处理通知去重、现有会话或保存个人设置的流程。

正式组件由 `DesktopNotificationSettings.vue` 呈现状态入口，`DesktopNotificationHelp.vue` 呈现选定的 B 弹窗。浏览器能力检测在 `use-desktop-notifications.js`；共享复制工具在原生模态内部创建 HTTP 回退复制字段，避免被浏览器的背景 inert 限制阻止。正式访问地址来自 `window.location.origin`，不会使用原型中的示例 IP。

# 初始化引导交互原型

打开 [initialization-guide.html](./initialization-guide.html) 即可体验；相邻 CSS、JS 与仓库设计变量文件需保持现有相对位置。支持直接用浏览器打开 HTML，也可以由本地静态服务器预览。

这是[初始化引导方案](../prd/initialization-guide.md)的评审材料，尚未接入生产应用。管理员在向导中创建；用户首次登录冒泡引导已移出范围。

## 体验路径

1. 创建管理员：使用演示密码，支持必填、长度和两次输入一致性校验。
2. 环境检测：模拟安装 Git/Codex；顶部“评审场景”可以切换失败、待重启、无安装器、检测异常、未认证和初始化链接失效。
3. 成员目录：修改路径、选择模拟目录、预览 Git 仓库名 / 登录用户名目录，或勾选“模拟目录不可写”查看错误反馈。
4. 部门与权限：查看产品 12 项、研发 13 项默认权限并创建。
5. 测试账号：可分别勾选创建，也可以全部跳过。请仅填写演示密码。
6. 第一个项目：填写演示名称和仓库地址，选择加入的测试成员，或跳过项目创建。
7. 查看结果并完成；“保存并退出”可以演示恢复流程，“重置演示”清空当前原型状态。

原型仅在当前标签页的 sessionStorage 中保存非敏感演示状态；密码只留内存，并在提交或退出时清除。所有创建和安装均为模拟，不发起业务 API 请求；校验不替代正式实现的服务端规则。正式状态将保存于 PostgreSQL，安装仍由受限的环境服务执行。

## 本轮验证

通过浏览器验证完整创建流程、可选步骤跳过、刷新恢复、密码不持久化、字段错误、目录选择 Escape 关闭、安装失败与重试、待重启、检测异常、初始化入口失效及完成门禁。

在 1440 / 768 / 390 / 320px 检查七个步骤，无页面横向溢出。验证截图和记录保存在忽略目录 `state/browser/initialization-prototype/`，不提交运行产物。

本轮没有修改生产代码，未执行全仓库构建或后端回归；正式实施的验证范围见方案中的验收清单。

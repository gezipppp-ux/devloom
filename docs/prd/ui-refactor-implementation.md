# B 方案正式实施

2026-10-13：用户已确认原型，授权全量替换并补齐现有项目和原型的功能差异。不维护旧数据兼容层，不对实际部署的数据执行迁移或清理。

## 合并原则

- 采用 B 方案的统一导航、留白、白色与石墨／紫色主题、跨项目入口和响应式布局。
- 保留现有权限、不可变流程、版本、Markdown／图片、个人 Git、任务合并、真实远端分支、会话审批、代码查看、MCP、供应商、初始化等完整能力。
- 新增真实的跨项目工作台、事项／本人开发任务／交付队列与搜索；所有查询遵循项目权限，会话仍属本人。
- 补充事项截止日期、标签；独立交付详情、验收核对、通过／退回及审计；验收与流程流转分别表达。
- 重复呈现抽为共享组件，业务表单和权限保留在功能内。共用 Markdown、附件、模型选择和反馈组件。

## 正式功能与原型的对应

2026-10-14，正式 Vue 实现位于 `codex/ui-refactor`。语言入口覆盖登录、首次改密、初始化及主壳层，默认中文，记住当前浏览器选择；切换不保存业务数据、不重建表单或会话。复用页面标题、空状态、状态标记、筛选、分页、原生模态窗口与语言选择器，原有 Markdown、附件、权限和模型组件继续复用。

| 范围 | 正式实现 |
| --- | --- |
| 工作台、搜索、事项／开发／交付 | `/api/workbench/issues|tasks|deliveries` 分页聚合；搜索限定授权项目，开发任务仅本人；查询完成后复核权限，包括计数来源 |
| 事项 | 增加截止日期、标签，校验输入并纳入修订冲突；主事项入口统一需求／Bug，项目内部保留两类分区 |
| 发布交付 | 事项搜索与分页选择、共享范围确认、标题和说明、关联任务、提交标识、冻结验收清单 |
| 验收 | 独立交付详情、逐项核对、通过／退回、原因、修订号与审计；可显式选择同时流转事项 |
| 权限与草稿 | 已归档内容只读；验收失权后清空受限详情和草稿；切换对象及卸载后迟到响应不恢复旧页面 |
| 国际化 | 界面标签、工具提示、可访问名称和已知反馈支持中英；用户正文、代码、自定义流程名、冻结业务记录保持原文；未知服务／Agent 诊断保留原文 |

原型继续用于中文视觉评审，模拟数据和动作不是正式 API 契约。特别是原型演示验收后直接改变事项状态；正式版本将验收与事项流转分开，默认只记录验收结论。项目内原有版本、权限、任务合并、实时远端分支、会话审批、Git、MCP、供应商和初始化能力按实际工程契约保留。没有实施生产部署或运行生产数据迁移。

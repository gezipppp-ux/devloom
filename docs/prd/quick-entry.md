# 项目选择与快捷搜索

2026-10-15 用户确认「精简列表弹窗」和「快捷搜索」，并要求独立开发共用项目选择弹窗。

- 项目选择由 `ProjectPickerDialog` 统一呈现。标题为「选择项目」，副标题说明新建需求、Bug、独立开发或历史会话的用途。列表行展示项目首字、名称、非空描述和进入箭头；单项目不增加筛选或第二次确认，超过五个项目时提供名称与描述过滤。
- App 继续按操作权限和项目状态筛选选项，并保留事项新建、个人开发空间和历史会话原有跳转。选择项目不会启动 Agent。空间读取期间可取消，关闭或重新打开后，旧响应不能导航、关闭新窗口或覆盖新的错误状态；取消保护延续到跳转前的 bootstrap 工作区读取。
- 全局搜索采用一条输入框与紧凑结果列表，移除重复标题、大块空提示和独立搜索按钮。空输入显示服务端真实最近项目；没有访问记录时展示可访问项目。输入停止 200ms 后查询项目、事项、本人开发与交付，沿用已有接口、权限和详情深链。
- `useGlobalSearch` 拥有防抖与请求代际；输入变化立即清除旧结果，卸载使未完成请求失效。部分查询失败时保留其他已确认结果并提供重试，不将请求失败显示成空结果。
- 搜索框自动获焦，方向键选择、Enter 打开、Escape 关闭并恢复触发按钮焦点。项目列表支持方向键与正常 Tab 顺序；所有弹窗保留原生模态焦点限制。
- 复用正式主题变量与中英文资源，窄屏重排并保持正常字号和可操作尺寸。搜索历史与草稿不写入本地存储。

回归使用模拟 API、隔离 PostgreSQL、临时 Git 与 fake Codex。新增浏览器断言与截图纳入 `visual.test.cjs`，覆盖权限过滤、独立开发取消后重开、搜索乱序、空态、重试、键盘、中英文及 320–2560px 布局。

2026-10-15 本地验收环境为 Windows / Chrome。完整 ESLint、622 项架构／单元／集成测试、生产构建和 Jenkins 的 9 个浏览器入口均通过；全站视觉回归生成 352 张截图，专项截图另存于 `state/browser/quick-entry/`。取消保护补齐后的最终构建再次通过快捷入口专项和工作区浏览器回归，已查看桌面、平板、手机、中英文及暗色截图。未在本机执行 Linux 或 macOS 验证。

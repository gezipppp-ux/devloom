# 事项新建入口与页面

2026-10-15 用户确认「按钮下拉 + 独立新建页」，并要求责任人与关注人移至左侧、日期与标签及人员字段全部展开。

- 工作台、事项列表和项目内的「新建事项」提供需求 / Bug 两个选项。跨项目入口选择类型后再选择有创建权限的项目。
- 进入新建页时隐藏项目大标题、项目导航、列表标题和列表操作，只保留一个新建标题与一组保存 / 取消按钮。保留当前项目与返回入口。
- 左侧为标题、描述、类型 / 流程所需正文，以及直接展开的责任人与关注人；四种职责按两列排列，关注人占整行。右侧为版本、优先级、Bug 严重程度，以及直接展开的截止日期和标签。
- 窄屏顺序重排为正文、责任人与关注人、事项属性。复用共享主题、AppSelect 和 MarkdownEditor，附件通用说明只出现一次。
- 沿用 `?tab=issues|bugs&create=1` 地址。页内切换类型保留公共字段、已有正文、人员和待保存附件，类型专属或流程要求的字段按真实流程呈现。
- 取消返回来源页面并清理附件草稿；保存失败保留草稿和幂等请求标识。成功后打开新事项，浏览器返回回到来源列表。
- 授权、流程版本、业务字段及保存接口不变；不启动 Agent。

实现与验证遵循仓库 UI / 工程契约，测试仅使用模拟 API、隔离 PostgreSQL 与 fake Codex。

2026-10-15 验证：完整 ESLint 和生产构建通过；架构、单元、集成共 622 个用例，首次 620 通过，另 2 个开发服务器用例因子进程切换目录后找不到相对环境文件而失败，改用绝对环境文件路径后该文件 3/3 通过。Jenkinsfile 中全部浏览器入口在 Windows / Chrome 通过，视觉回归生成 352 张截图，覆盖 320–2560px；已人工核对新建页桌面、平板、手机布局。新增断言覆盖需求 / Bug 下拉键盘操作、独立页去重、人员左侧布局、日期标签展开、类型及语言切换保留草稿、附件、失败重试与来源筛选恢复。未运行其他操作系统的实机验证。

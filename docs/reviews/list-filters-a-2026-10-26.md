# 常驻筛选条与来源信息

日期：2026-10-26。用户已选定 [A 方案](../prototypes/ui-refactor/list-filters/README.md)。状态：实现与回归完成。

## 实际变更

- `ListFilters` 为三个全局队列与项目内事项/开发列表提供常驻筛选条，复用可搜索多选 `AppSelect`；移动端使用共享模态框。
- 新增筛选元数据及组合查询，支持版本、状态、优先级、负责人和提报人。选项来自授权范围，不限于当前页；全局开发候选进一步限定为本人全部任务涉及的版本和人员。数据库 WHERE、计数和分页共用条件。
- 事项展示 `reporterId`，开发展示关联事项去重后的 `reporterIds`；交付区分事项提报人与交付提交人，并显示来源版本。无关联事项、未排期、待分派和历史成员均有明确呈现。
- 开发详情通过经过校验的项目图片映射显示需求快照正文图片，覆盖直接附件链接与导入来源别名。当前附件哈希不匹配快照时不替换原图片；不修改存储快照或执行记录。
- 条件保存在 URL，切换筛选清空分页和批量选择，列表返回与刷新保留条件。交付详情补齐同样的安全返回路径。

# 操作反馈统一：改造与验证

日期：2026-10-12。

## 最终行为

操作成功、失败、警告和普通消息统一显示为页面顶部居中的浮动提示，不再占据表单和页面布局。覆盖账号管理、登录与改密、个人 Git 账号、部门与项目协作、事项和附件、项目资产、系统和工作区设置、TAPD 检索、Agent 会话、代码查看及 Git 操作。

- 使用统一图标、语义颜色、白色消息卡片和关闭按钮；长文本换行，最多同时显示 4 条。
- 成功、普通、警告、错误提示分别在 4、5、8、10 秒后关闭；鼠标悬停或键盘聚焦时暂停，相同活动消息合并并保留暂停状态。
- 消息不抢输入焦点。原生模态框打开时，将消息宿主挂入当前模态框，并使用手动 popover 显示，保证提示可见且关闭按钮可操作。
- 账号代际变化清空提示，保留请求原有的上下文与卸载守卫。会导致组件卸载的成功操作直接发布反馈，避免保存成功后跳转丢失消息。
- 后台轮询的同一持续错误只报告一次，读取恢复后才重置；主动重试仍可报告结果。
- 字段校验、危险操作确认、进度、业务历史错误、只读限制和保存冲突解决区仍保留在所属界面。

共享实现位于 `web/src/shared/components/FeedbackMessage.vue`、`OperationMessages.vue` 和 `operation-messages.js`。清理了不再使用的局部提示状态和样式，更新 UI 契约和前端说明。

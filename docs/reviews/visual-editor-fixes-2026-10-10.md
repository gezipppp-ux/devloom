# 粘贴图片与可视编辑体验

用户反馈：粘贴图片后正文显示 Markdown 地址，附件区只有文件名，难以阅读和继续编辑。

## 修改

- 默认使用懒加载的 Tiptap 可视化编辑器，图片直接显示在正文，可在图前／图后继续输入；提供常用格式、撤销／重做、Markdown 源码和预览切换。
- 图片和普通附件以缩略图／文件卡片呈现，包含名称、大小和移除按钮。待保存状态清晰标注，沿用正文与附件原子保存。
- Markdown 存储及现有权限不变。图片节点只加载已验证映射，blob 仅用于草稿预览；网页／文档剪贴板取纯文本，HTML 不执行。不能无损转换的 Markdown 保留原文，提供源码编辑入口。
- 异步插图保留并映射光标位置。源码读取附件期间锁定输入，避免偏移；初始化、外部合并及移除附件重设撤销基线，撤销不会恢复已删除的待存文件引用。
- 修正行内图片使用块级样式导致方向键未退出图片选区的问题，避免图后中文输入替换图片。

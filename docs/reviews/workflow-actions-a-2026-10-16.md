# 流程按钮反查与 A 方案实施

日期：2026-10-16。本轮完成本地实现与验证后，按用户授权部署到现有 Linux 服务。未执行数据库迁移、发布生产流程或改写真实事项。

## 反查结论

运行时没有把事项的目标状态固定到 ready、rework、pending_verification 等节点。固定节点 ID 只用于构造可载入的默认/推荐模板；实际执行按事项绑定的已发布版本定位当前节点和事件出线。原有不足主要是界面固定操作名称、部分入口没有采用完整能力结果，以及无新版本仍显示采用入口。本轮移除了按任务状态切换送验文案的分支，也撤销了规划类别限制，避免代码与流程配置产生两套规则。

| 入口 | 配置来源与修正 |
| --- | --- |
| 事项人工流转 | 当前节点的 manual 连线、操作主体和权限；提交按钮显示所选连线名称 |
| 事项/讨论/任务送验 | delivery.submitted 连线的 name、from、to、actor、permission；无出线不显示，不按任务是否启动写死名称 |
| 成果弹窗 | 标题及提交名称跟随选中事项的送验连线；复用原交付字段、验证人与共享确认 |
| 开始验证/验证通过/退回 | 对应 verification 事件的名称、目标和权限；同时校验当前指定验证人、交付轮次及状态；无配置或无权不显示 |
| 返工重新提交 | 原交付链资格与当前 deliverySubmission.allowed 同时满足；按钮使用当前连线名称 |
| 开发执行 | 节点 allowDevelopment 与 development.started 配置；单一配置动作显示其名称，多事项先使用通用执行准备；真实 turn-started 才推进流程 |
| 指派/认领 | 节点 allowAssignment 与 development.assigned 配置，保留执行人资格及认领约束；分配当前开发步骤的处理人不虚构新的状态转换 |
| 工作台/通知 | 保留导航用途，配置的开发开始、验证开始、返工送验名称通过 workflowLabel 呈现 |
| 采用新流程版本 | 最新已发布版本大于绑定版本，并继续检查权限、步骤和任务兼容条件 |
| 模板/交接预览 | 读取推荐定义或当前草稿；载入、保存、发布明确区分，预览不执行业务操作 |

`trigger`、`actor`、`assignment` 和权限是引擎支持的协议类型；管理员配置具体来源、目标、名称和规则。开发任务状态、Agent 状态、交付验收结论、幂等与账号权限仍是系统独立约束，不能通过改流程绕过。导航、保存、取消、查看任务等通用界面操作不代表事项状态转换。

已有 JSON 流程定义字段足够，本轮无数据库新增字段、迁移或回填。新增的版本号、allowed、transitionId、workflowLabel 等均为接口展示字段。

## A 方案交付

侧栏集中办理；成果使用同一弹窗；流程模板和交接预览按需打开；保存与发布集中在页头，全屏画布保留操作；单条和批量指派留在当前页面并刷新；开发列表默认只排除已取消，保留显式全部/已取消筛选和独立归档规则。

## 验证

- ESLint 和生产构建已通过，构建仍有既有的大包提示。
- 架构、单元、隔离 PostgreSQL 集成共 663 项全部通过，无跳过。
- 专项浏览器覆盖动态操作名称、版本入口、表单冲突保留、模板仅载入草稿、交接预览、单条/批量指派留页、开发筛选和中英文。
- Jenkins 规定的九组浏览器脚本在 Windows / Edge 全部通过；正式页面视觉回归生成 352 张截图，覆盖桌面、平板、移动端，无横向溢出或提示重叠。已人工复核事项侧栏、成果弹窗、流程模板、交接预览、流程画布及全屏布局，包括 320px 和 390px 窄屏。
- 部署机完成 Linux 构建和启动检查；局域网页面、会话接口及前端文件校验通过，未认证业务接口正确返回 401，启动日志无错误。保留程序回滚备份，现有配置、数据目录和业务 Worktree 路径不变。
- 完整回归平台为 Windows / Edge；本轮未在 Linux、macOS 或其他浏览器平台运行完整测试。

# 移除项目归属部门：改造与验证

日期：2026-10-12。承接同日项目直接引入仓库的改造，本文更新项目与部门的最终关系。

## 最终行为

- 项目不归属部门，创建只填写名称、说明和 Git 仓库地址；负责人、成员、仓库和业务内容仍归项目管理。
- 用户仍属于一个有效部门，部门限定功能上限；账号创建资格继续生效。项目成员关系决定访问范围，成员授权与用户部门权限取交集，同部门非成员不会自动获得访问权。
- 项目名称允许重复，以 UUID 区分项目及其业务数据和目录。
- 删除项目的部门字段、关联、复合唯一索引、输入校验分支、响应字段、查询关联、创建用部门目录和界面控件；旧 `departmentId` 输入按未知字段拒绝，不提供兼容分支。
- 账号和成员的部门信息、权限上限说明及管理员首次设置本人部门的准备清单保留。
- PRD、README、用户手册及工程契约同步更新。

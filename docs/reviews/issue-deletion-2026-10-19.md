# 需求/Bug 删除功能验收

2026-10-19，正式 Vue 与后端实现；本轮未部署、未修改真实业务数据。

## 范围与交互

用户确认只删除未关联开发任务和交付记录的事项。详情沿用 A 方案：编辑在标题右侧，删除收进其后的「更多操作」，流程办理继续位于侧栏；移动端标题下方重排。使用现有确认弹窗，显示事项编号、标题、不可撤销的页面访问影响和关联限制。取消与 Escape 返回入口，提交期间阻止重复操作，冲突需要刷新后重新确认；成功回到原筛选列表并清理所删事项的选中状态。

删除使用独立 `issue.delete` 权限，管理员自动具有此权限，普通成员遵循部门上限和项目授权；既有授权不自动改变。所有历史开发关联（包括取消、完成、合并）与交付均阻止删除。归档项目及版本保持只读。

采用逻辑删除，保留来源、编号、正文、讨论、附件和审计；公开查询及附件下载排除已删除事项，工作台步骤结束，项目/版本统计和归档门禁同步更新。MCP 原发布请求及结果查询不会返回或恢复已删除事项。没有新增 MCP 删除工具。

# MCP 删除需求与 Bug

2026-10-19，补充已实现的事项删除能力。本轮按用户要求只构建，不更新服务器；测试执行按此前要求跳过。

## 实现

- 新增 `delete_issue({projectId,issueId,requestId,revision})`，复用 `ProjectContentServices.deleteIssue`；归档、修订、任何开发任务与交付历史的限制保持一致。
- 使用独立 Token scope `issues.delete` 与项目权限 `issue.delete`，旧 Token 不自动扩权，新建 Token 表单默认不勾选删除；复用已有中文和英文权限文案。
- 删除、结果记录和审计在同一事务完成；同一请求原样重试返回删除回执，参数冲突返回 409，新请求删除已删除事项返回 404。删除回执仅含 `id/deleted`，不会读取被删除正文；回执查询同样要求当前删除授权。
- MCP 工具说明、工程契约、用户指南和公开 Skill 同步更新。技能版本为 `1.1.5`，包含目标核对、用户授权、修订冲突和响应丢失后的恢复流程。
- 不新增数据库迁移，不更改现有 Token 或任何真实事项。

# 管理员项目权限与账号显示名称

日期：2026-10-12。按最终确认的“查看并管理所有项目的成员、配置及协作内容”实现；本记录更新此前项目改造报告中管理员也必须加入项目、先配置本人部门的规则。

## 最终行为

- 管理员首页为「全部项目」，包含归档项目；不要求部门或项目成员关系，即可创建项目及管理成员、配置、需求／Bug、评论、交付和普通资产。
- 管理员全局权限使用显式名单，在普通成员依赖闭包计算后合并，不能补足代码、Agent 或敏感字段的授权依赖。个人开发空间始终按所有者隔离，浏览项目不会隐式加入项目或分配开发空间。
- 归档写保护、有效负责人交接、停用负责人限制和最后管理员保护保留。管理员角色撤销后按普通成员重新授权。
- 成员界面区分部门上限、项目授权和管理员全局权限，显示实际有效权限；无部门管理员负责人可以保存空项目授权，仍不获得开发或敏感权限。
- 用户名用于登录，显示名称用于界面展示；账号管理和人员选择显示双名帮助区分。显示名称支持中文及重名，去除首尾空白后为 1–80 个字符，禁止控制字符。
- 管理员可创建／修改账号显示名称，用户可在个人设置修改自己的显示名称。单独改名不撤销登录或 SSE，不修改账号身份或目录；迟到响应不能覆盖其他账号或最新权限。

# 桌面通知连接指引 · B 方案

日期：2026-10-23。用户选择居中弹窗，并要求将 HTTPS 与临时内网站点例外明确区分为两种方式。

## 完成范围

- 个人设置在浏览器安全上下文不满足要求时显示连接提示；安全上下文中的权限拒绝、API 不支持单独提示。
- 弹窗用两张可选择的选项展示“方式一 · 使用 HTTPS 访问（推荐）”与“方式二 · 临时允许当前内网站点”。默认 HTTPS，步骤互斥展示，明确无需同时设置；手机单列重排。
- 临时方式提供 Chrome / Edge 操作步骤、地址复制和状态重新检测。当前站点地址从 `window.location.origin` 获取，包含协议、主机和端口，不包含页面路径；正式代码没有原型示例 IP。
- 仅点击可用的通知开关才申请浏览器权限／保存偏好；重新检测和恢复焦点只读取状态。保留账号代际和卸载检查。
- 共享复制工具的 HTTP 回退字段放入当前原生模态，避免背景 inert 阻止复制；恢复原焦点并保留失败反馈。
- 中文／英文和浅色／暗色使用现有共享能力。未修改后端业务或部署配置。

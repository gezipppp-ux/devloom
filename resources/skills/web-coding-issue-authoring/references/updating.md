# 安装与更新

技能名称为 `web-coding-issue-authoring`。入口、references、agents 和 scripts 使用同一个版本，版本写在 `SKILL.md` 的 `metadata.version` 中。本技能不迁移、读取或覆盖其他技能。

## 地址来源

- 已连接：用本次选定连接的 `whoami.skills.manifestUrl`；站点用 `whoami.runtime.siteOrigin`。不能假设 Agent 能读取客户端隐藏的 MCP 配置。
- 首次配置：用用户提供的安装清单地址或公开指南中的地址。没有任何地址时先请求入口，不能猜 IP。
- 安装记录 `.installation.json` 由更新程序生成，包含来源、版本和文件哈希，不含 Token；该文件不属于发布包。安装后不随意换源。不同部署使用各自的安装位置或明确重新安装，不把另一部署当作同一来源的新版。

## 首次安装

1. 不带凭据 GET 清单，使用 `Cache-Control: no-cache`。校验 `schemaVersion: 1`、名称、三段数字版本及同源地址，拒绝重定向。
2. 选择当前客户端支持的技能目录，首次安装目标应尚不存在，目录名必须为 `web-coding-issue-authoring`；父目录可已存在。需要 Node.js 22.13+；不可用时说明缺少运行时，不宣称安装完成。
3. 下载清单内 `scripts/update-skill.cjs` 到临时位置，对照清单校验文件大小及 SHA-256，再运行该脚本。不要只把入口保存到目标目录，也不要直接运行未经校验的下载文件。
4. 将真实清单 URL 和目标绝对路径作为两个参数传入：

```text
node <已校验的脚本路径> --source <清单URL> --directory <技能目录绝对路径>
```

5. 检查程序成功结果，再读取目标目录的 `SKILL.md` 及所需 references。配置 MCP 和凭据单独进行；客户端需要重载时明确说明。

网页也提供 ZIP 供人工查看或下载；自动安装使用清单内固定版本文件逐个下载并校验，不依赖额外解压工具。只下载 ZIP 不代表已安装或已建立更新记录。

## 每轮更新

运行已安装的 `scripts/update-skill.cjs`，传入本轮 `whoami` 返回的同源清单地址和当前技能目录。每轮一次，不必在每次 MCP 调用前重复执行。

程序获取完整清单，按数字比较版本；相同版本不重写、较旧版本不降级。同版本内容变化视为发布错误。它校验已安装文件是否被修改或增删，有本地改动时停止并保留内容，不自动覆盖或删除。

新版文件下载到同级临时目录，逐一验证大小、SHA-256、入口名称与版本、所有相对文档引用，然后在更新锁内切换完整目录；切换失败恢复原目录。仅操作该技能目录，不更新 MCP 凭据或其他技能。多个更新进程不能同时写入。

返回 `installed`、`updated`、`current` 或 `remote-older` 后，按实际版本说明结果。`remote-older` 不表示与当前服务端版本一致，先核实部署版本，暂缓业务写操作。任何网络、哈希、来源、本地修改、权限或切换错误均保留原版本，继续只读查询与草稿，暂缓写操作。进程被强制终止留下锁或备份时，先核实没有更新进程，再恢复备份；不得直接删除备份重装。

更新只在使用技能时执行，不会自行在后台运行。客户端缺少网络、Node.js 或本地写权限时如实说明限制。

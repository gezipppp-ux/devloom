# B 方案 · 中性协作界面

从 [UI 重构 PRD](../../../docs/prd/ui-refactor.md)、[设计图册](../../../docs/prd/assets/ui-refactor/index.html) 和 [HTML 原型](../../../docs/prototypes/ui-refactor/review.html) 理解目标。用户选定的 B 方案提供通用视觉基线；具体功能沿用后续确认的布局与交互，避免用基线覆盖用户的新选择。新增交互的设计与交付流程见 [web-coding-ui](../web-coding-ui/SKILL.md#新增交互先设计整页)。

## 视觉判断

- 白色为主体，浅冷灰划分层次，石墨色主按钮，紫色只用于选中、焦点和少量标记。参考 [tokens.css](assets/tokens.css)，不要把生成图里的渐变、阴影和文字误差照搬成规则。
- 每屏一个清晰标题和主要行动。把高级配置、批量操作和低频字段放在需要时出现的位置；为当前任务保留充足空间。
- 新入口放入完整页面判断视觉权重：日常操作易于找到，低频工具不与主操作并列争夺注意力。新增功能使原区域拥挤时，先整理信息层级和分组，再确定按钮、表单的位置。
- 一条主侧栏：工作台、项目、事项、开发、交付。个人设置和管理中心在低频区。人员参与多种活动，页面不提供产品经理／研发角色开关或不同岗位首页。
- 页面以列表、正文和轻分隔线组织。卡片用于独立对象或分区，不把每个字段、每条信息都套进卡片。避免大量彩色指标、厚重边框和重复标题。
- 字体、图标、图表由 HTML/CSS/SVG 清晰绘制；生成图片仅作设计参考，不能铺成业务页面或作为文字控件。

## 响应式实现

屏幕物理分辨率不等于 CSS 视口。按可用宽度重排，不能对 1536×1024 效果图使用整体缩放、固定画布或强制最小桌面宽度。

| CSS 宽度 | 页面行为 |
| --- | --- |
| 320–767 | 单列；抽屉导航和五项底栏；详情侧栏进入折叠区；操作目标至少 44px；表格转可读条目，代码局部滚动 |
| 768–1199 | 紧凑侧栏；列表优先，详情上下排列或使用抽屉；表单两列只在字段仍有足够空间时使用 |
| 1200–1919 | 208px 侧栏；常规内容最大 1440px，详情正文约 760–880px，辅助区约 300px |
| ≥1920 | 常规内容最大 1600px，协作／代码工作区可扩到 1920px；增加上下文空间，不同步放大字号和控件 |

正文 14–16px，页面标题 28–32px，辅助文字不小于 12px。正文行宽有上限，表单不横向铺满 2K。空间使用 `minmax(0, 1fr)`、`min-width: 0`、`clamp()` 和内容驱动高度。

长页面使用浏览器正常滚动；桌面会话可使用独立消息滚动区，输入框保持可达。移动端使用 `dvh`、安全区留白，软键盘和短视口不能遮住提交入口。动画尊重 `prefers-reduced-motion`。

## 关键状态

同一页面的加载、空、失败、禁用、只读、权限失效和冲突沿用同一布局。当前动作的进度及错误靠近该动作；错误保留输入。弹窗有标题、取消、Escape、焦点限制及返回触发点，危险动作描述真实影响。

事项、开发任务和 Agent 状态分别呈现。认领／分派不会执行；启动要有明确确认。项目交付可共享，个人会话与代码只供所有者访问。权限依据业务契约，不由导航样式推断。

## 验收

至少查看 1920×1080、2560×1440、1440×900、1280×720、768×1024、390×844 和 320×740 的实际 CSS 视口。检查本次受影响的页面、表单／弹窗及短屏滚动；共享组件改动覆盖其相关页面。检查横向溢出、可点击范围、焦点和文字可读性。高 DPR 只提高绘制精度，不改变布局密度。

对本次受影响的完整页面逐项判断，不能只检查溢出或组件样式：

- **主次**：用户能辨认当前最主要的动作；次要和低频入口的权重合理，没有多个同样突出的按钮争抢焦点。
- **密度**：正文、表单或画布保有足够空间；按钮组、提示和说明没有挤占主体，宽屏没有无意义拉伸，窄屏没有简单压缩桌面布局。
- **简洁**：没有重复标题、重复入口和逐字段套卡片；说明服务于当前决策，必要条件和错误仍清楚可见。
- **一致性**：字体层级、间距、对齐、按钮和表单行为与已确认方案及相邻页面一致，优先使用共享组件和设计变量。
- **真实内容**：长文本、多操作、空与失败状态，以及英文和移动端仍保持上述层次，不能只凭理想数据下的截图判定通过。

视觉问题应在交付前调整并复查。功能可用与视觉合格是两项独立结论；自动截图和布局断言不能替代查看实际截图。
